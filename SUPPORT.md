# Support

For usage questions and reproducible bugs, use [GitHub Discussions](https://github.com/aqamasters/ai-workflows-pe/discussions) or [Issues](https://github.com/aqamasters/ai-workflows-pe/issues) with synthetic/public examples. Run `aqa-ai-workflows doctor` first and include its non-secret output, application version, OS, Python/Git versions, provider name/model, and safe error message.

Never post API keys, GitHub tokens, private repository links, client source, Context Packs, or raw provider payloads.

[Security reports](https://github.com/aqamasters/ai-workflows-pe/security/advisories/new) belong in GitHub private vulnerability reporting. AQA Managed Delivery support and professional services are separate from this community-supported Public Edition.
